How to Add Custom Overlays in GitOps (Custom Hierarchy)

You can define your own topology dimensions (e.g. regions/, clouds/, teams/, datacenters/) by creating a hierarchy.yaml file in the root of your GitOps repository:

# hierarchy.yaml in your Git repository layers: - level: 1 name: "Base" path: "base.yaml" description: "Fleet-wide baseline defaults" - level: 2 name: "Cloud-Provider" path: "clouds/{{.Cloud}}.yaml" dimensions: ["Cloud"] description: "AWS, GCP, Azure specific settings" - level: 3 name: "Region" path: "regions/{{.Region}}.yaml" dimensions: ["Region"] description: "Regional datacenter routing" - level: 4 name: "Environment" path: "environments/{{.Environment}}.yaml" dimensions: ["Environment"] - level: 5 name: "Role" path: "roles/{{.Role}}.yaml" dimensions: ["Role"] - level: 6 name: "Host" path: "hosts/{{.Hostname}}.yaml" dimensions: ["Hostname"] - level: 7 name: "Redis-TTL" type: "redis" path: "redis:override:{{.Hostname}}" description: "Temporary operational override (Highest Precedence)"
